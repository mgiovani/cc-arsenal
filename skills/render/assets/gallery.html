Risk

A corrupted count becomes the next run's baseline, so the generator never flags the same rewrite twice. Both bugs would have stayed silent.

Decision

Match group headings by shape with GROUP_HEADING_RE, not by "is a heading". A skill body may carry its own ### Usage.

Note

Both regression tests were verified to fail against the pre-fix code before the fix landed.

Frame

Disclosure

Why anchors come from content, not positionfeedback-loop.md

A position-derived anchor like step-3 still resolves after a step is inserted above it, so a comment silently moves to different work. Deriving it from the content's own identifier breaks loudly instead.

Why the page never serializes the live DOM

The runtime captures the document source before any render, then swaps only the state block into it. Rendered rows never leak into the saved file.
