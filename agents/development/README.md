# Development Agents

Senior developers specializing in code implementation, debugging, testing, and best practices.

## Purpose

Development agents provide expertise in:
- Code implementation and debugging
- Testing strategies and implementation
- Development best practices
- Technical problem-solving
- Code quality and performance optimization

## Development

Development agents should focus on:
- Writing clean, maintainable code
- Implementing comprehensive tests
- Following security best practices
- Optimizing for performance
- Adhering to coding standards

## Tools

Common tools for development agents:
- Read, Write, Edit, MultiEdit for code manipulation
- Bash for build and test commands
- Glob, Grep for code analysis
- TodoWrite for task management
