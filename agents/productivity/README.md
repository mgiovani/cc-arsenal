# Productivity Agents

Productivity specialists focused on development efficiency, automation, and workflow optimization.

## Purpose

Productivity agents provide expertise in:
- Development workflow optimization
- Task automation and scripting
- Tool selection and configuration
- Process improvement and efficiency
- Time management and prioritization

## Development

Productivity agents should focus on:
- Identifying repetitive tasks for automation
- Streamlining development workflows
- Optimizing tool usage and configuration
- Reducing friction in common processes
- Measuring and improving productivity metrics

## Tools

Common tools for productivity agents:
- Bash for automation scripts
- Read, Write for configuration files
- TodoWrite for task optimization
- Glob, Grep for workflow analysis
