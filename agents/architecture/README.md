# Architecture Agents

System architects specializing in application design, technology selection, and infrastructure planning.

## Purpose

Architecture agents provide expertise in:
- Holistic application design
- Technology selection and evaluation
- API design and integration patterns
- Infrastructure planning and deployment
- Performance and scalability considerations

## Development

Architecture agents should focus on:
- High-level system design decisions
- Technology stack recommendations
- Architectural pattern guidance
- Infrastructure design and planning
- Performance optimization strategies

## Tools

Common tools for architecture agents:
- Read, Write, Edit for documentation
- Bash for infrastructure commands
- Glob, Grep for codebase analysis
- TodoWrite for planning complex architectural changes
