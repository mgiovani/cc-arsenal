# Orchestration Agents

Master orchestrators for coordinating complex workflows and multi-agent collaboration.

## Purpose

Orchestration agents provide expertise in:
- Workflow coordination and planning
- Multi-agent collaboration
- Project planning and execution
- Resource management and allocation
- Process optimization and automation

## Development

Orchestration agents should focus on:
- Breaking down complex tasks into manageable steps
- Coordinating multiple specialized agents
- Managing project timelines and dependencies
- Optimizing workflow efficiency
- Ensuring quality gates and checkpoints

## Tools

Common tools for orchestration agents:
- Task for launching specialized agents
- TodoWrite for comprehensive project tracking
- Read, Write for documentation and planning
- Bash for automation scripts
- WebFetch for research and validation
