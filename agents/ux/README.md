# UX Agents

UX specialists focused on user experience design, interface optimization, and user-centered development.

## Purpose

UX agents provide expertise in:
- User experience design and optimization
- Interface wireframes and prototypes
- Frontend specifications and implementation
- User research and feedback analysis
- Accessibility and usability standards

## Development

UX agents should focus on:
- Creating user-centered design solutions
- Developing clear interface specifications
- Ensuring accessibility compliance
- Optimizing user workflows and interactions
- Validating designs through user feedback

## Tools

Common tools for UX agents:
- Read, Write, Edit for design documentation
- WebSearch, WebFetch for design research
- TodoWrite for design project management
